Detailed Description

A dataclass(-like) decorator with custom parameters.

.. code:: python

    @dataclass(init=True) # this
    class A: ...

    @dataclass_transform
    def create_model(*, init=False): pass

    @create_model(init=False) # or this
    class B: ...
