OpenADSB-Out

Proyecto open source para el desarrollo de un transmisor ADS-B Out (1090ES) de bajo coste, diseñado desde el inicio con una arquitectura compatible con futuras certificaciones aeronáuticas.

‍Estado: Concepto / Arquitectura inicial

Objetivos

Objetivo principal

Desarrollar un transmisor ADS-B Out basado en componentes comerciales de bajo coste, evitando el uso de SDR y utilizando una arquitectura modular y verificable.

Objetivos secundarios

  • Hardware completamente documentado.
  • Firmware open source.
  • Arquitectura preparada para certificación futura.
  • Autodiagnóstico (BIT).
  • Supervisión continua del sistema.
  • Diseño modular.
  • Bajo coste de fabricación.
  • Compatible con drones experimentales, aeronaves ligeras y entornos de laboratorio.

Alcance

El proyecto implementará:

  • ADS-B Out 1090ES
  • Mensajes DF17
  • Posición GNSS
  • Velocidad
  • Identificación de aeronave
  • Estado del sistema
  • Monitorización interna

No incluye inicialmente:

  • TCAS
  • Modo A/C
  • Modo S interrogado
  • Certificación ETSO/TSO
  • Diversidad de antenas

Política de Seguridad

El transmisor debe inhibirse automáticamente cuando:

  • No exista posición válida.
  • Se detecte fallo GNSS.
  • Exista fallo PLL.
  • La potencia RF esté fuera de límites.
  • La configuración sea inválida.

Estado:

NO VALID POSITION
→ NO TRANSMISSION

Registro de Fallos

Cada fallo debe registrar:

  • Timestamp
  • Código de error
  • Estado GNSS
  • Estado RF

Objetivo:

Facilitar certificación futura y análisis post-fallo.

Filosofía del Proyecto

Diseñar desde el primer día como si el sistema fuese a certificarse en el futuro, aunque inicialmente se utilice exclusivamente para investigación, laboratorio y desarrollo experimental.

La certificación debe ser una evolución del proyecto, no una reescritura completa.
